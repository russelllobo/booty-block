# App Store screenshots

Capture screenshots from the final production build on a physical iPhone after the EAS build is installed.

Recommended sequence:

1. Home screen showing the blocked state
2. Apple app/category selection picker
3. Unlock-duration selection
4. Live squat-counting session with the full-body overlay
5. Earned-time success screen
6. Settings with privacy and support links

Do not use web-fallback or generated screenshots: the App Store images should accurately show the submitted iOS binary and its native Screen Time and camera experiences.
